# Habisolo — Investor Landing Page

A standalone Next.js investor pitch landing page for Habisolo, covering the
problem, product ecosystem, market opportunity, business model, traction,
funding round and founder vision.
/
## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

## Project Structure

- `src/components/investors/` — page sections (Hero, Business Model, Market
  Opportunity, Founder Vision, etc.)
- `public/images/` — page imagery
